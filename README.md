# Office Management System - Java

A console-based Office Management System built with Java. This project manages employees, attendance, leaves, and salary calculations using Object-Oriented Programming concepts.

## Features

- Add Full-Time and Part-Time employees
- Store employee information
- Mark employee attendance
- Apply and manage leaves
- Calculate employee salaries
- Display all employees
- Salary validation
- Custom exception handling
- Maximum working days and leave limits
- Full-time employee bonus
- Part-time employee bonus

## Employee Types

### Full-Time Employee
- Salary is calculated based on working days
- Maximum working days: 31
- Receives a bonus of 500 when all 31 working days are completed

### Part-Time Employee
- Salary is calculated based on working days
- Receives a 5% bonus when more than 20 days are worked

## Office Rules

- Maximum working days: 31
- Maximum leaves: 2 days
- Negative salary is not allowed
- Invalid salary and attendance/leave conditions generate custom exceptions
